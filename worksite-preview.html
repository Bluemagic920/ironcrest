Location accuracy policy

For the production design, Ironcrest should evaluate distance and the device's reported uncertainty together. A location estimate whose uncertainty overlaps the boundary should be treated as uncertain, not automatically approved.

  • Employer configures one or more worksites; only authorized owners/managers can edit them.
  • Employee location is requested only when an attendance action is initiated.
  • Server verifies identity, organization membership, worksite assignment, accuracy, and timestamp.
  • Uncertain or missing locations require manager-reviewed exceptions.
  • GPS can be spoofed; location alone is not proof of physical presence.

This prototype deliberately does not request your location, use external maps, call Supabase, or create attendance records.
